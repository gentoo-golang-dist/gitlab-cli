Revoke a personal access token for a service account.

## Synopsis

Revoke a personal access token for a service account in a group.

If multiple tokens share the same name, specify the token ID
to select the correct one.

```plaintext
glab service-account token revoke <token-name|token-id> [flags]
```

## Aliases

```plaintext
rm
```

## Examples

```console
# Revoke a token by name
glab service-account token revoke my-token --service-account my-bot --group my-group

# Revoke a token by ID
glab service-account token revoke 12345 --service-account my-bot --group my-group
```

## Options

```plaintext
  -g, --group string             The group the service account belongs to (required).
  -F, --output string            Format output as: text, json. 'text' provides the name and ID of the revoked token; 'json' outputs the token with metadata. (default "text")
  -R, --repo string              Select another repository. You can use either OWNER/REPO or GROUP/NAMESPACE/REPO. The full URL or Git URL is also accepted.
      --service-account string   The service account name or numeric ID (required).
```
