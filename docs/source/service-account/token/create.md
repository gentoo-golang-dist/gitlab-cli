Create a personal access token for a service account.

## Synopsis

Create a new personal access token for a service account in a group.

The expiration date of the token is calculated by adding the duration
(default: 30 days) to the current date. You can specify a different
duration using days (d), weeks (w), or hours (h), or provide an
explicit end date.

The token value is printed to stdout.

```plaintext
glab service-account token create <token-name> [flags]
```

## Examples

```console
# Create a token with API scope
glab service-account token create my-token --service-account my-bot --group my-group --scope api

# Create a token with multiple scopes and 90 day lifetime
glab service-account token create my-token --service-account my-bot --group my-group --scope api --scope read_registry --duration 90d

# Create a token with explicit expiration date
glab service-account token create my-token --service-account 12345 --group my-group --scope api --expires-at 2025-12-31
```

## Options

```plaintext
      --description string       Description of the token.
  -D, --duration duration        Sets the token lifetime. Accepts: days (30d), weeks (4w), or hours in multiples of 24 (24h). Maximum: 365d. (default 30d)
  -E, --expires-at DATE          Sets the token's expiration date, in YYYY-MM-DD format. If not specified, --duration is used. (default 0001-01-01)
  -g, --group string             The group the service account belongs to (required).
  -F, --output string            Format output as 'text' for the token value, 'json' for the full token object. (default "text")
  -R, --repo string              Select another repository. You can use either OWNER/REPO or GROUP/NAMESPACE/REPO. The full URL or Git URL is also accepted.
  -S, --scope strings            Scopes for the token (required). Use multiple flags or comma-separated values.
      --service-account string   The service account name or numeric ID (required).
```
