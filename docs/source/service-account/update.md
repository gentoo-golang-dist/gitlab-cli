Update a service account in a group.

## Synopsis

Update a service account's name or username.

This API endpoint works on top-level groups only. It does not
work on subgroups.

```plaintext
glab service-account update [flags]
```

## Examples

```console
# Update a service account's name
glab service-account update --service-account my-bot --group my-group --name "New Name"

# Update a service account's username by numeric ID
glab service-account update --service-account 12345 --group my-group --username new-bot-name
```

## Options

```plaintext
  -g, --group string             The group the service account belongs to (required).
      --name string              New name for the service account.
  -F, --output string            Format output as: text, json. (default "text")
  -R, --repo string              Select another repository. You can use either OWNER/REPO or GROUP/NAMESPACE/REPO. The full URL or Git URL is also accepted.
      --service-account string   The service account name or numeric ID (required).
      --username string          New username for the service account.
```
