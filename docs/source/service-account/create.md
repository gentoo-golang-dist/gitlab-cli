Create a service account in a group.

## Synopsis

Create a new service account in a group. The name, username,
and email are optional and will be auto-generated by GitLab
if not specified.

This API endpoint works on top-level groups only. It does not
work on subgroups.

```plaintext
glab service-account create [flags]
```

## Examples

```console
# Create a service account with auto-generated attributes
glab service-account create --group my-group

# Create a service account with a specific name
glab service-account create --group my-group --name "CI Bot"

# Create a service account with all attributes specified
glab service-account create --group my-group --name "CI Bot" --username ci-bot --email ci-bot@example.com
```

## Options

```plaintext
      --email string      Email of the service account.
  -g, --group string      The group to create the service account in (required).
      --name string       Name of the service account.
  -F, --output string     Format output as: text, json. (default "text")
  -R, --repo string       Select another repository. You can use either OWNER/REPO or GROUP/NAMESPACE/REPO. The full URL or Git URL is also accepted.
      --username string   Username of the service account.
```
