Read a file from a repository at a specific ref. (EXPERIMENTAL)

## Synopsis

Print the contents of a single file from a GitLab repository at a specific
commit, branch, or tag. No local clone required.

The default output is raw bytes, suitable for piping or redirecting to a file.
Use `--output json` for a structured response containing metadata such as
`blob_id`, `commit_id`, and `last_commit_id`. The `content`
field in JSON mode is base64-encoded (matching the GitLab REST API).

Pass a SHA to `--ref` (rather than a branch name) for results that are
immutable and cacheable.

This feature is an experiment and is not ready for production use.
It might be unstable or removed at any time.
For more information, see
<https://docs.gitlab.com/policy/development_stages_support/>.

```plaintext
glab agent file get <path> [flags]
```

## Examples

```console
# Read README.md at the tip of the main branch
glab agent file get README.md --ref main

# Read a file at a specific commit, structured output
glab agent file get docs/index.md --ref 1a2b3c4d --output json

# Read a file from a different repository
glab agent file get internal/main.go --repo gitlab-org/cli --ref main

# Resolve an LFS pointer to the underlying binary and save it to disk
glab agent file get assets/big.bin --ref main --lfs > big.bin

```

## Options

```plaintext
      --lfs               If the path is an LFS pointer, resolve to the underlying binary. Only applies with --output text.
  -F, --output string     Format output as: text, json. (default "text")
  -r, --ref string        Branch, tag, or commit SHA to read from. Required.
  -R, --repo OWNER/REPO   Select another repository. Can use either OWNER/REPO or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.
```
