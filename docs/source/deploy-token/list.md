List deploy tokens for a project or group.

```plaintext
glab deploy-token list [flags]
```

## Examples

```console
# List deploy tokens for the current project
$ glab deploy-token list

# List deploy tokens for a specific group
$ glab deploy-token list --group my-group

# List only active deploy tokens
$ glab deploy-token list --active

```

## Options

```plaintext
  -a, --active         Limit to active deploy tokens only.
  -g, --group string   List deploy tokens for a group instead of a project.
  -p, --page int       Page number. (default 1)
  -P, --per-page int   Number of items to list per page. (default 30)
```
