Create a deploy token for a project or group.

```plaintext
glab deploy-token create <name> [flags]
```

## Aliases

```plaintext
new
```

## Examples

```console
$ glab deploy-token create "CI Token" --scopes read_repository
$ glab deploy-token create "Registry" --scopes read_registry,write_registry --expires-at 2025-12-31
$ glab deploy-token create "Group Token" --scopes read_repository -g mygroup
$ glab deploy-token create "CI Token" --scopes read_repository --output json

```

## Options

```plaintext
  -e, --expires-at string   Expiration date of the deploy token (YYYY-MM-DD format, e.g. 2025-12-31).
  -g, --group string        Create deploy token for a group. Ignored if -R/--repo is set.
  -F, --output string       Format output as: text, json. (default "text")
  -R, --repo OWNER/REPO     Select another repository. Can use either OWNER/REPO or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.
  -s, --scopes strings      Scopes for the deploy token. Options: read_repository, read_registry, write_registry, read_package_registry, write_package_registry.
  -u, --username string     Username for the deploy token. Defaults to gitlab+deploy-token-{n}.
```
