Create a deploy token for a project or group.

```plaintext
glab deploy-token create [flags]
```

## Aliases

```plaintext
new
```

## Examples

```console
$ glab deploy-token create --name "CI Token" --scopes read_repository
$ glab deploy-token create --name "Registry" --scopes read_registry,write_registry --expires-at 2025-12-31
$ glab deploy-token create --name "Group Token" --scopes read_repository -g mygroup

```

## Options

```plaintext
  -e, --expires-at string   Expiration date of the deploy token (ISO 8601 format, e.g. 2025-12-31).
  -g, --group string        Create deploy token for a group.
  -n, --name string         Name of the deploy token.
  -s, --scopes strings      Scopes for the deploy token. Options: read_repository, read_registry, write_registry, read_package_registry, write_package_registry.
  -u, --username string     Username for the deploy token. Defaults to gitlab+deploy-token-{n}.
```
